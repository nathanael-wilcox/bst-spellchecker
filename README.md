## Spellchecker with Lazy-balanced Binary Search Tree

This project is a spellchecker built off of a lazy-balanced binary search tree. The tree only rebalances a node once one side is twice as large as the other and had a height greater than 3. This tree is then filled with every word in 'words.txt', which is roughly every word in the dictionary. The spellchecker allows you to add words, remove words, and scan every word in a document to check it with the dictionay tree. If the word is not in the dictionary, it allows you to add it.

This was a project I completed for one of my programming classes.
